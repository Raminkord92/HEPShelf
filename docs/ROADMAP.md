# HEPShelf roadmap

## Implemented through 0.9

- local watched-folder indexing;
- arXiv metadata and discovery;
- integrated PDF reading and reading-position memory;
- tags, collections, authors and categories;
- metadata-based move/rename workflows;
- BibTeX export;
- INSPIRE citation counts and references;
- selective missing-reference downloads;
- citation-aware PDF reader with local-reference following;
- cited-by browser and selective citing-paper downloads;
- interactive citation graph;
- controlled multi-hop graph expansion from any node;
- progressive cited-by loading, local-node matching, and graph deduplication;
- autosaved per-paper research notes;
- named ordered literature trails containing local or remote papers;
- per-trail-item notes, trail reordering, and trail export;
- saving citation-graph exploration order as a literature trail.

## Candidate 0.10 work

- saved smart searches;
- INSPIRE author identity / BAI support to merge author-name variants;
- background refresh policies for metadata and citation counts;
- optional alerts for newly citing papers or new arXiv papers by selected authors;
- improved reference matching for records lacking arXiv IDs or DOIs;
- export citation graph as SVG/PNG or Graphviz;
- import/export of literature trails as a portable HEPShelf JSON format;
- optional note view inside the PDF reader.

## Later

- full-text local search;
- semantic search as an optional layer over deterministic metadata indexing;
- citation-context search across the local library;
- export/import of full HEPShelf collections;
- cross-platform packaging and signed releases.
