01 / READ

Own your library.

Index folders you choose, search papers and notes, and read PDFs in a native viewer. Your library metadata lives in local SQLite.

HEPShelf is an open-source Qt desktop app. Build it on Linux Mint or Ubuntu and point it at the PDFs you already have.

$ ./build/hepshelf
